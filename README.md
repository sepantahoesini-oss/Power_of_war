# POWER OF WAR — Season 8

ساختار پروژه فقط دو رابط دارد: `public/index.html` سایت اصلی و `public/admin.html` پنل مدیریت. بک‌اند در `src/worker.js` است.

## نکته مهم دیتابیس
این پروژه برای حفظ کاربران قبلی طراحی شده است. `schema.sql` جداول سیزن ۸ را با پیشوند `s8_` می‌سازد و جدول `users` را حذف یا بازسازی نمی‌کند. بنابراین می‌توان D1 قبلی کاربران را به Worker جدید متصل کرد و حساب‌های POW را نگه داشت.

اگر جدول `users` قدیمی ستون `victories` و `blocked_type` داشته باشد، Worker همان ستون‌ها را تشخیص می‌دهد؛ اگر `wins` و `block_type` داشته باشد نیز پشتیبانی می‌شود.

## Cloudflare
1. D1 مورد استفاده برای حساب‌های قبلی را نگه دارید.
2. جداول `schema.sql` را روی همان D1 اجرا کنید.
3. در `wrangler.json` مقدار `database_id` را با Database ID واقعی جایگزین کنید.
4. Secret با نام `ADMIN_PASSWORD` را در Worker تنظیم کنید.
5. Deploy کنید.

## نکته امنیتی
رمز مدیریت داخل فایل‌ها قرار نگرفته و باید فقط به‌صورت Cloudflare Secret تنظیم شود.
